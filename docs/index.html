PRISMA 2020 準拠 定性エビデンス統合レポート

PICO形式・研究特性表・合意点・不一致点・バイアスリスク・GRADE格付けを構造化して生成します。

「PRISMAレポートを生成」ボタンを押すと、採択されたオープンジャーナル研究群の包括的なメタ分析レポートが出力されます。

メタ分析データ (CSV)

採用論文の効果量、95% CI、サンプルサイズ、DOI、OA URLをExcel互換CSVでダウンロードできます。

学術文献引用 (BibTeX)

LaTeXやZotero、Mendeleyなどの文献管理ツールにインポート可能なBibTeX形式でダウンロードします。

PRISMA 2020 チェックリスト

選定フローの各段階における数値と除外理由の内訳サマリーをテキスト形式で保存します。

Gemini API 設定

Google Gemini API キーを設定すると、採択論文の高度なPRISMA定性エビデンス統合レポート（Gemini 2.5 Flash）が生成されます。
※未設定の場合でも、内蔵の高精度NLPエンジンにより完全オフラインで動作します。
