1. 各種統計指標のリファレンス

効果量 (Effect Size: SMD / Hedges' g)

効果の大きさ

異なる測定尺度（テストの得点や評価スコア等）を共通基準で比較できるように、介入群と対照群の平均値の差を標準偏差で割って標準化した指標です。小規模研究のサンプルバイアスを補正した Hedges' g を採用しています。

Cohenによる判定基準 (目安):
  • |g| ≈ 0.20: 小さな効果（Small Effect）
  • |g| ≈ 0.50: 中等度の効果（Medium Effect）- 実質的・臨床的に意義がある水準
  • |g| ≈ 0.80以上: 大きな効果（Large Effect）- 肉眼や日常でも実感できる明確な差

固定効果モデル vs 変量効果モデル

統合モデル

複数の研究結果を1つの総合ダイヤモンドに統合する際の統計学的「仮定」の違いです：

固定効果 (Fixed-Effect / Inverse-Variance):

全研究に共通する単一の真の効果が存在し、差は標本誤差のみと仮定。条件が同一の研究群でのみ妥当。

変量効果 (Random-Effects / DerSimonian-Laird): 【推奨】

患者背景や用量、実施環境の違いにより「真の効果自体が研究ごとに分布している」と仮定。医学・生命科学・臨床メタ分析の標準。

異質性統計量 (I² 統計量 & Cochran's Q)

ばらつきの評価

研究ごとの結果の食い違いが「偶然の誤差」か「研究条件の違い（異質性）」かを判定する指標です。

0% 〜 25%: 低度
研究間で結果が一貫し強固
25% 〜 50%: 中等度
臨床試験で一般的な範囲
50% 〜 75%: 高度
条件差（サブグループ）要検討
75% 〜 100%: 著しい
単純統合の解釈に強い注意要
Cochran's Q 検定: 帰無仮説「異質性なし」。検出力を考慮し一般に p < 0.10 で有意な異質性ありと判断します。

95% 信頼区間 (95% CI) & p 値

推定精度と確信

真の効果量が95%の確率で含まれる数値区間です。

✅ 統計的有意 (p < 0.05):

信頼区間が無効果線 (差は0.0、比は1.0) をまたいでいない状態。偶然による差ではないと判定されます。

⚠️ 有意差なし (p ≥ 0.05):

信頼区間が無効果線を含んでいる状態（例: -0.10 to +0.40）。現データでは効果の有無を断定できません。

3. 結果をどう読み解くのか：実践5ステップフロー

01

Step 1: 統合ダイヤモンドの位置と有意性を確認する

最下部の統合ダイヤモンド（◆）が無効果線（0.0 または 1.0）のどちら側にあり、無効果線をまたいでいないかを確認します。またいでいなければ「統計的に有意 (p < 0.05)」で介入効果が実証されています。

02

Step 2: 効果の「大きさ（臨床的意義）」を評価する

統計的有意（p < 0.05）であっても、効果量が極小（SMD = 0.08等）では実用上の価値は限定的です。SMD ≥ 0.50（中等度）やOR ≤ 0.70など、日常や臨床で実質的な変化をもたらす大きさがあるかを吟味します。

03

Step 3: 異質性 (I²) を点検し、研究間の一致度を調べる

$I^2 < 25\%$ なら全研究がほぼ同じ結論を示しており強固です。もし $I^2 > 50\%$ の場合は研究条件（年齢層、投与量、期間）による違いがあるため、必ず変量効果モデル (Random Effects) の結果を採用します。

04

Step 4: 個別研究の重みの偏り・外れ値がないか確認する

1つの巨大研究が重みの過半数を占めて全体結果を独占していないか、他の研究と正反対の極端な結果を出している研究がないかを確認し、結果の頑健性（ロバストネス）を確かめます。

05

Step 5: バイアスリスクとGRADE確信度を総合して意思決定する

採用研究の質（ランダム化・盲検化）や未公表論文の可能性（出版バイアス）を考慮し、GRADE確信度（High / Moderate / Low / Very Low）を踏まえて現実の意思決定や結論を導き出します。

4. 実践ケーススタディ（典型例で学ぶ判定パターン）

ケース A: 強いエビデンス 明確な有効性
統合効果 (RE): SMD = 0.65
95% CI: [0.42, 0.88] (p < 0.001)
異質性 I²: 18.5% (p = 0.29)

95% CIが無効果線0を大きく上回って有意。効果量0.65（中〜大）で実質的な改善あり。異質性18.5%と低く、複数研究で再現性が実証された高水準のエビデンス。

ケース B: 高異質性 慎重な解釈要
統合効果 (RE): SMD = 0.38
95% CI: [-0.05, 0.81] (p = 0.082)
異質性 I²: 74.2% (p < 0.001)

95% CIが無効果線0を含み有意差なし。$I^2 = 74.2\%$ と研究間の食い違いが大きいため、単純統合での断定は禁物。投与量や対象層別のサブグループ分析が必要。

ケース C: リスク低減 リスク42%減
統合オッズ比 (RE): OR = 0.58
95% CI: [0.45, 0.74] (p < 0.001)
異質性 I²: 32.0% (p = 0.16)

オッズ比が無効果基準1.0を大幅に下回り（上限0.74）、発症リスクが約42%有意に抑制されたと解釈。異質性も中等度以下で信頼できる結果。
