PRISMA 2020 メタ分析レポート作成＆ダウンロード

各採用論文への直接リンク（DOI / OA全文 / PDF）付きの特性一覧表、PICO形式、合意・不一致点、バイアスリスク、GRADE格付けを網羅した学術レポートを出力・保存します。

レポートのダウンロード形式:

各論文へのリンク付きエビデンスを総合分析し、PRISMA 2020 構造化レポートを編成中...

上の「PRISMAレポートを作成」ボタンをクリックすると、海外オープンジャーナル論文群のリンク付きメタ分析レポートが表示されます。

関連データ＆図表の即座ダウンロード:

メタ分析データ (CSV)

採用論文の効果量、95% CI、サンプルサイズ、DOI、論文直リンクをExcel互換CSVでダウンロードできます。

学術文献引用 (BibTeX)

LaTeXやZotero、Mendeleyなどの文献管理ツールにインポート可能なBibTeX形式でダウンロードします。

PRISMA 2020 チェックリスト

選定フローの各段階における数値と除外理由の内訳サマリーをテキスト形式で保存します。

Gemini API 設定

Google Gemini API キーを設定すると、日本語キーワードの高度な学術英語翻訳および採択論文のPRISMA定性エビデンス統合レポート（Gemini 2.5 Flash）が生成されます。
※未設定の場合でも、無料のオープン翻訳APIおよび内蔵NLPエンジンにより完全動作します。
